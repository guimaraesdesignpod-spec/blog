# Quero Contratar

Construo **pipelines de automação com IA** para desenvolvedores, criadores de conteúdo e pequenos negócios.

## O Que Faço

- **Fábricas de conteúdo** — Pipelines de IA que pesquisam tópicos trending, geram artigos e publicam automaticamente
- **Web scraping & automação de pesquisa** — Transformo dados espalhados em insights estruturados
- **Orquestração de agentes** — Fluxos multi-agente que lidam com tarefas complexas em várias etapas
- **Blog setup & SEO** — Blogs multilíngues com hreflang correto, canonical URLs e dados estruturados

## Tech Stack

- Next.js / Vercel (deploy)
- Hermes Agent + OpenClaw (orquestração de IA)
- Python (pipelines de dados)
- Hacker News API, Jina AI, Firecrawl (pesquisa)
