# LLMs Locais vs APIs Cloud: A Verdadeira Comparação de Custos em 2026

Todo mundo fala em rodar LLMs localmente para economizar. Quase ninguém publica os números reais. Acompanhei custos por 6 meses com Ollama (local), OpenAI e Anthropic. Aqui está o que as faturas realmente dizem.

## A Configuração

Eu dirijo uma pequena consultoria de IA. Minha carga de trabalho: ~500 tarefas de agentes por mês, com uma média de 8.000 tokens cada (prompt + resposta). São 4 milhões de tokens por mês. Veja o que isso custa em três cenários:
 | **Local (RTX 4090)** | **OpenAI (GPT-5.3)** | **Anthropic (Claude 4.6)** | **Híbrido**
**Tokens mensais** | Ilimitados | 4M | 4M | 4M
**Hardware** | $1.800 (único) | $0 | $0 | $1.800
**Eletricidade** | $45/mês | $0 | $0 | $45/mês
**Custo da API** | $0 | $240/mês | $360/mês | $60/mês
**TCO (1 ano)** | $2.340 | $2.880 | $4.320 | $2.520
**TCO (3 anos)** | $3.420 | $8.640 | $12.960 | $5.940

## Quando o Local Ganha

Os LLMs locais arrasam as APIs cloud quando:

### 1. Volume Alto, Tarefas Simples

Se seus agentes fazem classificação, extração ou sumarização (as tarefas chatas que representam 80% das cargas de trabalho de IA), um Qwen 3.5 ou Llama 4 rodando numa GPU de $2.000 processa mais de 100 requisições por minuto. Nas taxas da OpenAI, isso custaria $0,50 por mil tokens. Localmente, custa $0,00.

Exemplo real: Meu agente de pipeline de conteúdo classifica 2.000 artigos por dia por tópico. Com GPT-5: $18/dia. Com Qwen 3.5 local: $0,45/dia (eletricidade). Economia: $6.400/ano.

### 2. Dados Sensíveis

Saúde, jurídico, financeiro. Se seus dados não podem sair da rede, a conversa acaba aqui. O "custo" de uma violação de dados não é algo que se coloca numa planilha.

### 3. Latência Importa

Inferência local: 20-50ms por token. API OpenAI: 200-500ms por token. Para aplicações em tempo real, isso faz diferença. Um chatbot que demora 3 segundos para responder perde usuários.

## Quando a Cloud Ganha

### 1. Raciocínio Complexo

Peça a um modelo local para planejar uma implantação de software em 10 etapas. Ele chega na etapa 4 e alucina um comando de Kubernetes que não existe. GPT-5 e Claude 4.6 lidam com isso de forma confiável. O custo extra é um seguro contra outputs ruins.

### 2. Volume Baixo

Se você faz 50 chamadas de API por mês, a conta é trivial. Mesmo a $5 por chamada, são $250/mês — mais barato do que comprar e manter uma GPU.

### 3. Manutenção Zero

LLMs locais exigem: atualizar modelos, gerenciar quantização, debugar erros CUDA às 2 da manhã e explicar para a equipe por que o servidor caiu. APIs cloud exigem: um cartão de crédito.

## A Abordagem Híbrida (O Que Realmente Funciona)

Depois de 6 meses de experimentação, aqui está o que funcionou:

    ┌─────────────────────────────────────┐
    │           ORQUESTRADOR              │
    │         (Cloud: GPT-5/Claude)       │
    │   Planeja, raciocina, decompõe      │
    └──────────────┬──────────────────────┘
                   │
           ┌───────┴───────┐
           ▼               ▼
    ┌─────────────┐ ┌─────────────┐
    │  WORKER A   │ │  WORKER B   │
    │  (Local)    │ │  (Cloud)    │
    │  Qwen 3.5   │ │  GPT-5.3    │
    │  Extração   │ │  Geração    │
    └─────────────┘ └─────────────┘

**A regra:** Cloud para pensar, local para fazer. Planejamento, raciocínio, geração complexa → cloud. Extração, classificação, chamadas simples de ferramentas → local.

Essa configuração híbrida custa 60% menos do que usar só cloud e dá conta de 95% das tarefas.

## FAQ

### P: E o Apple Silicon?

Macs M3/M4 com 64 GB+ de memória unificada rodam Llama 4 34B a 15-22 tokens/seg. O hardware é caro ($4.000+), mas a eletricidade é desprezível e o aparelho é totalmente silencioso. Boa opção se você já tem um.

### P: A qualidade com quantização é aceitável?

Quantização em 4-bit custa ~5% de qualidade por 50% menos VRAM. Para extração e classificação, funciona bem. Para geração, fique com 8-bit ou acima.

### P: Posso usar GPUs na cloud (Lambda, RunPod) em vez de comprar hardware?

Sim, e isso muda as contas. Lambda Labs A100: $1,10/hora. Para 500 tarefas de agentes/mês (média de 3 segundos cada), são 25 minutos = $0,46/mês em tempo de GPU. Mas você perde o benefício de estar "sempre disponível" e adiciona latência de cold start.

## Conclusão

Se você processa mais de 1 milhão de tokens por mês, compre uma GPU e rode localmente. Se processa menos, use APIs cloud. Se processa mais de 10 milhões, compre duas GPUs e aprenda a amar os drivers CUDA.

**O sweet spot híbrido:** GPT-5/Claude para orquestração e geração complexa. Qwen 3.5/Llama 4 local para todo o resto. É onde a maioria das equipes acaba depois do primeiro ano.
