# LLMs Locais vs APIs Cloud: A Verdadeira Comparação de Custos em 2026

Toda a gente fala em correr LLMs localmente para poupar dinheiro. Quase ninguém publica os números reais. Tenho acompanhado custos há 6 meses com Ollama (local), OpenAI e Anthropic. Eis o que as faturas realmente dizem.

## A Configuração

Dirijo uma pequena consultoria de IA. A minha carga de trabalho: ~500 tarefas de agentes por mês, com uma média de 8.000 tokens cada (prompt + resposta). São 4 milhões de tokens por mês. Eis o que isso custa em três cenários:

| | Local (RTX 4090) | OpenAI (GPT-5.3) | Anthropic (Claude 4.6) | Híbrido |
|---|---|---|---|---|
| **Tokens mensais** | Ilimitados | 4M | 4M | 4M |
| **Hardware** | $1.800 (único) | $0 | $0 | $1.800 |
| **Eletricidade** | $45/mês | $0 | $0 | $45/mês |
| **Custo da API** | $0 | $240/mês | $360/mês | $60/mês |
| **TCO (1 ano)** | $2.340 | $2.880 | $4.320 | $2.520 |
| **TCO (3 anos)** | $3.420 | $8.640 | $12.960 | $5.940 |

## Quando o Local Ganha

Os LLMs locais vencem as APIs cloud quando:

### 1. Volume Elevado, Tarefas Simples

Se os seus agentes fazem classificação, extração ou sumarização (as tarefas aborrecidas que representam 80% das cargas de trabalho de IA), um Qwen 3.5 ou Llama 4 a correr numa GPU de $2.000 processa mais de 100 pedidos por minuto. Às taxas da OpenAI, isso seria $0.50 por mil tokens. Localmente, é $0.00.

Exemplo real: O meu agente de pipeline de conteúdos classifica 2.000 artigos por dia por tópico. Com GPT-5: $18/dia. Com Qwen 3.5 local: $0.45/dia (eletricidade). Poupança: $6.400/ano.

### 2. Dados Sensíveis à Privacidade

Saúde, jurídico, financeiro. Se os seus dados não podem sair da rede, a conversa termina aqui. O "custo" de uma violação HIPAA não é algo que se coloque numa folha de cálculo.

### 3. A Latência Importa

Inferência local: 20-50ms por token. API OpenAI: 200-500ms por token. Para aplicações em tempo real, isto importa. Um chatbot que demora 3 segundos a responder perde utilizadores.

## Quando a Cloud Ganha

### 1. Raciocínio Complexo

Peça a um modelo local para planear uma implementação de software em 10 passos. Ele chega ao passo 4 e alucina um comando de Kubernetes que não existe. GPT-5 e Claude 4.6 lidam com isto de forma fiável. O custo extra é um seguro contra outputs incorretos.

### 2. Volume Baixo

Se faz 50 chamadas de API por mês, as contas são triviais. Mesmo a $5 por chamada, são $250/mês — mais barato do que comprar e manter uma GPU.

### 3. Manutenção Zero

LLMs locais exigem: atualizar modelos, gerir quantização, debugar erros CUDA às 2 da manhã e explicar à equipa porque é que o servidor está em baixo. APIs cloud exigem: um cartão de crédito.

## A Abordagem Híbrida (O Que Realmente Funciona)

Após 6 meses de experimentação, eis o que funcionou:

```
┌─────────────────────────────────────┐
│           ORCHESTRATOR              │
│         (Cloud: GPT-5/Claude)       │
│   Plans, reasons, decomposes tasks  │
└──────────────┬──────────────────────┘
               │
       ┌───────┴───────┐
       ▼               ▼
┌─────────────┐ ┌─────────────┐
│  WORKER A   │ │  WORKER B   │
│  (Local)    │ │  (Cloud)    │
│  Qwen 3.5   │ │  GPT-5.3    │
│  Extraction │ │  Generation │
└─────────────┘ └─────────────┘
```

**A regra:** Cloud para pensar, local para fazer. Planeamento, raciocínio, geração complexa → cloud. Extração, classificação, chamadas simples de ferramentas → local.

Esta configuração híbrida custa 60% menos do que tudo cloud e processa 95% das tarefas.

## FAQ

### P: E o Apple Silicon?

Macs M3/M4 com 64 GB+ de memória unificada correm Llama 4 34B a 15-22 tokens/seg. O hardware é caro ($4.000+), mas a eletricidade é negligenciável e é completamente silencioso. Boa opção se já tiver um.

### P: A qualidade quantizada é aceitável?

Quantização a 4-bit custa ~5% de qualidade por 50% menos VRAM. Para extração e classificação, é aceitável. Para geração, mantenha 8-bit ou superior.

### P: Posso usar GPUs cloud (Lambda, RunPod) em vez de comprar hardware?

Sim, e isso altera as contas. Lambda Labs A100: $1.10/hora. Para 500 tarefas de agentes/mês (média de 3 segundos cada), são 25 minutos = $0.46/mês em tempo de GPU. Mas perde o benefício "sempre disponível" e adiciona latência de cold start.

## Conclusão

Se processa mais de 1 milhão de tokens por mês, compre uma GPU e corra localmente. Se processa menos, use APIs cloud. Se processa mais de 10 milhões, compre duas GPUs e aprenda a amar os drivers CUDA.

**O sweet spot híbrido:** GPT-5/Claude para orquestração e geração complexa. Qwen 3.5/Llama 4 local para todo o resto. É aqui que a maioria das equipas acaba após o primeiro ano.
